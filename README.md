# 🚍 Painel de Rotas Universitárias

Painel web interativo desenvolvido para organizar e consultar rotas, horários, instituições de ensino atendidas, valores mensais, regras de transporte e locais de atendimento da **Viação Sertanezina**.

O projeto foi construído com foco em eficiência, design limpo e utilidade prática para estudantes da região de Sertãozinho, Ribeirão Preto, Guariba e Jaboticabal.

## ⚠️ Regras de Embarque e Conduta
- 🪪 O embarque é permitido **apenas com a carteirinha carimbada** e atualizada.
- 🚫 É proibido **sujar o ônibus** com embalagens de comida ou lixo.
- 🎧 Não é permitido colocar **música alta** (uso obrigatório de fones de ouvido).
- 🚭 Estritamente **proibido fumar** no interior do veículo.
- 🚫 Proibido o consumo de **bebidas alcoólicas**.

## ⚙️ Funcionalidades e Diferenciais
- **Carregamento Dinâmico (JSON):** Separação inteligente dos dados das rotas em um arquivo `routes.json` consumido via JavaScript assíncrono (`fetch`).
- **Assistente Virtual GenAI:** Chatbot inteligente integrado na interface capaz de responder dúvidas dos estudantes em linguagem natural sobre rotas, valores e regras.
- **Busca em Tempo Real:** Filtro instantâneo por nome de faculdade, cidade ou termos na barra de pesquisa.
- **Indicador de Status Operacional:** Verifica automaticamente se o serviço está operando ou encerrado com base nos dias úteis e horários.
- **Design Responsivo:** Paleta em tons pastéis customizada e adaptada para diferentes tamanhos de tela.
