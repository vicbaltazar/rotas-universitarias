# 🚍 Painel de Rotas Universitárias

Painel web interativo desenvolvido para organizar e consultar rotas, horários, instituições de ensino atendidas, valores mensais e regras de transporte de linhas universitárias (Viação Sertanezina).

O projeto foi construído com foco em eficiência, design limpo e utilidade prática para estudantes da região de Sertãozinho, Ribeirão Preto, Guariba e Jaboticabal.

---

## ⚙️ Funcionalidades
* **Busca em Tempo Real:** Filtre instantaneamente por nome de faculdade, cidade ou valor digitando na barra de pesquisa.
* **Indicador de Status Operacional:** Verifica automaticamente se o serviço está operando ou fechado com base nos dias úteis da semana.
* **Design Responsivo:** Adaptado para diferentes tamanhos de tela.
